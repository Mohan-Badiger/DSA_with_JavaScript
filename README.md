## 🏃 How to Run Any Script

Ensure you have **Node.js** installed, then run any file with:

```bash

node DSA/Array/twosum.js

# Running SDE Fresher pattern solutions
node DSA-Mastery_JS/01-Arrays/09-dutch-national-flag-and-intervals.js
node DSA-Mastery_JS/02-Strings/02-sde-string-patterns.js

node DSA-Mastery_JS/07-Searching-Algorithms/02-binary-search-patterns.js
node DSA-Mastery_JS/09-Trees/02-sde-tree-patterns.js

```
