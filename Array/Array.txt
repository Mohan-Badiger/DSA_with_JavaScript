Array :
An array is a special type of object used to store an ordered collection of multiple values under a single variable name.

Advantages:
1.Store Multiple values.
2.Store All type of Datatypes like String, Number,Boolean,Object,Array etc.
3.It can be resized i.e., we can add or remove elements from it.
4.Easy to traverse using for loop,map,filter etc.
5.Built in methods like push,pop,shift,unshift,splice,slice,concat,map,filter,reduce etc.

Disadvantages:
1.Slow Performance due to dynamic memory allocation.
2.Memory Overhead.

Array Methods:
1. push() - Adds one or more elements to the end of an array and returns the new length.
   Example:
   let fruits = ["apple", "banana"];
   fruits.push("mango");          // returns 3
   console.log(fruits);           // ["apple", "banana", "mango"]

2. pop() - Removes the last element from an array and returns that element.
   Example:
   let fruits = ["apple", "banana", "mango"];
   let removed = fruits.pop();    // "mango"
   console.log(fruits);           // ["apple", "banana"]

3. unshift() - Adds one or more elements to the beginning of an array and returns the new length.
   Example:
   let fruits = ["banana", "mango"];
   fruits.unshift("apple");       // returns 3
   console.log(fruits);           // ["apple", "banana", "mango"]

4. shift() - Removes the first element from an array and returns that element.
   Example:
   let fruits = ["apple", "banana", "mango"];
   let removed = fruits.shift();  // "apple"
   console.log(fruits);           // ["banana", "mango"]

5. splice() - Adds/removes elements from an array. Mutates the original array.
   Syntax: array.splice(startIndex, deleteCount, item1, item2, ...)
   Example:
   let colors = ["red", "green", "blue"];
   colors.splice(1, 1, "yellow", "pink");  // removes "green", adds "yellow" & "pink"
   console.log(colors);           // ["red", "yellow", "pink", "blue"]

6. slice() - Returns a shallow copy of a portion of an array. Does NOT mutate the original.
   Syntax: array.slice(startIndex, endIndex)  // endIndex is exclusive
   Example:
   let nums = [1, 2, 3, 4, 5];
   let sliced = nums.slice(1, 4); // [2, 3, 4]
   console.log(nums);             // [1, 2, 3, 4, 5]  (unchanged)

7. forEach() - Executes a function once for each array element. Returns undefined.
   Example:
   let nums = [1, 2, 3];
   nums.forEach((num, index) => {
       console.log(`Index ${index}: ${num}`);
   });
   // Index 0: 1
   // Index 1: 2
   // Index 2: 3

8. map() - Creates a new array with the results of calling a function on every element.
   Example:
   let nums = [1, 2, 3, 4];
   let doubled = nums.map(num => num * 2);
   console.log(doubled);          // [2, 4, 6, 8]

9. filter() - Creates a new array with elements that pass a test (return true).
   Example:
   let nums = [1, 2, 3, 4, 5, 6];
   let evens = nums.filter(num => num % 2 === 0);
   console.log(evens);            // [2, 4, 6]

10. reduce() - Reduces the array to a single value by applying a function against an accumulator.
    Syntax: array.reduce((accumulator, currentValue) => { ... }, initialValue)
    Example:
    let nums = [1, 2, 3, 4];
    let sum = nums.reduce((acc, curr) => acc + curr, 0);
    console.log(sum);              // 10

11. some() - Returns true if at least one element passes the test.
    Example:
    let nums = [1, 3, 5, 8, 9];
    let hasEven = nums.some(num => num % 2 === 0);
    console.log(hasEven);          // true  (because 8 is even)

12. every() - Returns true only if ALL elements pass the test.
    Example:
    let nums = [2, 4, 6, 8];
    let allEven = nums.every(num => num % 2 === 0);
    console.log(allEven);          // true

13. sort() - Sorts the array in place. By default sorts as strings (Unicode order).
    Example:
    let nums = [40, 100, 1, 5, 25];
    nums.sort((a, b) => a - b);    // ascending numeric sort
    console.log(nums);             // [1, 5, 25, 40, 100]

14. fill() - Fills all or part of an array with a static value.
    Syntax: array.fill(value, startIndex, endIndex)
    Example:
    let arr = [1, 2, 3, 4, 5];
    arr.fill(0, 2, 4);
    console.log(arr);              // [1, 2, 0, 0, 5]

15. flat() - Creates a new array with all sub-array elements flattened to a specified depth.
    Example:
    let nested = [1, [2, 3], [4, [5, 6]]];
    console.log(nested.flat());    // [1, 2, 3, 4, [5, 6]]   (depth 1)
    console.log(nested.flat(2));   // [1, 2, 3, 4, 5, 6]     (depth 2)

16. copyWithin() - Copies part of an array to another location in the same array without changing its length.
    Syntax: array.copyWithin(targetIndex, startIndex, endIndex)
    Example:
    let arr = [1, 2, 3, 4, 5];
    arr.copyWithin(0, 3, 5);      // copies elements at index 3-4 to index 0
    console.log(arr);              // [4, 5, 3, 4, 5]

17. indexOf() - Returns the first index at which a given element is found, or -1 if not found.
    Example:
    let fruits = ["apple", "banana", "mango", "banana"];
    console.log(fruits.indexOf("banana"));   // 1
    console.log(fruits.indexOf("grape"));    // -1

18. includes() - Returns true if the array contains the specified element, false otherwise.
    Example:
    let nums = [1, 2, 3, 4, 5];
    console.log(nums.includes(3));   // true
    console.log(nums.includes(9));   // false

19. find() - Returns the first element that satisfies the provided testing function, or undefined.
    Example:
    let users = [{name: "Alice", age: 25}, {name: "Bob", age: 30}];
    let user = users.find(u => u.age > 26);
    console.log(user);              // {name: "Bob", age: 30}

20. findIndex() - Returns the index of the first element that satisfies the testing function, or -1.
    Example:
    let nums = [10, 20, 30, 40];
    let index = nums.findIndex(num => num > 25);
    console.log(index);             // 2
